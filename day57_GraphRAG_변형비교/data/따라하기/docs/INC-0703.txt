결제 완료 알림 지연 장애 보고서
발생일: 2026년 7월 3일
영향: 19시 15분부터 20시 5분까지 결제는 정상 승인되었지만 결제 완료 푸시가 최대 25분 늦게 도착했다. 알림 지연 때문에 같은 결제를 다시 시도한 사용자가 생겨 중복 결제 취소 요청이 640건 들어왔다.
타임라인 요약: 19:15 notify-hub(알림 허브)의 발송 지연 지표가 올랐다. 19:28 notify-hub 자체는 정상이고, 결제 완료 이벤트가 늦게 들어오는 것을 확인했다. 19:40 pg-connector(PG 연동 모듈)가 한빛PG의 승인 결과 통보를 받는 구간에서 응답이 밀리는 것을 찾았다. 한빛PG가 통보 서버를 점검하면서 통보를 묶어 늦게 보내고 있었다. 20:05 한빛PG 점검이 끝나며 회복되었다.
직접 원인: 외부 PG사인 한빛PG의 승인 결과 통보가 늦어져, 결제 완료 이벤트 발행도 늦어졌다.
근본 원인: 결제 완료 표시와 알림 발송이 PG사 통보에만 기대고 있었다. 승인 응답을 먼저 받은 경우에도 통보가 올 때까지 기다리도록 짜여 있었다.
조치: 점검 시간 동안 들어온 중복 결제 취소를 한꺼번에 처리했다.
재발 방지: 승인 응답을 받으면 바로 결제 완료 이벤트를 내고, 통보는 확인 용도로만 쓰도록 바꾼다. PG사 점검 일정을 미리 받아 앱에 안내 문구를 띄운다.
