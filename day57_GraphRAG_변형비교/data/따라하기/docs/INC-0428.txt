카드 결제 승인 지연 장애 보고서
발생일: 2026년 4월 28일
영향: 12시 5분부터 12시 41분까지 한빛PG를 거치는 카드 결제의 응답 시간이 평균 0.8초에서 9초로 늘었다. 이 가운데 약 7,900건은 앱의 대기 한도를 넘어 결제 실패로 끝났다. 점심 시간대라 음식점 가맹점의 항의가 많았다.
타임라인 요약: 12:05 결제 응답 시간 경보가 울렸다. 12:12 pg-connector(PG 연동 모듈)에서 한빛PG 구간만 느린 것을 확인했다. 12:20 한빛PG 상황실에 문의해 승인 서버 증설 작업 중이라는 답을 받았다. 12:24 신규 카드 결제를 다온PG로 돌리도록 라우팅 비율을 바꿨고 12:41 응답 시간이 정상으로 돌아왔다.
직접 원인: 외부 PG사인 한빛PG의 승인 서버가 작업 중 처리 용량이 줄어 응답이 늦어졌다.
근본 원인: pg-connector의 한빛PG 호출 대기 시간이 30초로 길게 잡혀 있어, PG사 응답 지연이 곧바로 pay-gateway(결제 게이트웨이)의 작업 스레드를 붙잡았다. 다른 PG사로 돌리는 판단도 사람이 해서 손으로 바꿔야 했다.
조치: 한빛PG 호출 대기 시간을 5초로 줄이고 라우팅 비율을 원래대로 돌렸다.
재발 방지: PG사별 응답 시간이 기준을 넘으면 자동으로 다른 PG사로 넘기는 규칙을 만든다. PG사와 작업 일정을 미리 공유받는 절차를 맺는다.
