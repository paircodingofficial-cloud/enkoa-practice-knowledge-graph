포인트·알림 영역과 공통 구성요소 카탈로그
기준일: 2026-09-30
포인트, 쿠폰, 알림 서비스와 여러 영역이 함께 쓰는 공통 구성요소를 적는다.
point-engine(포인트 적립 엔진): kafka-main(메인 메시지 브로커)에서 결제 완료 이벤트를 받아 적립 규칙에 따라 포인트를 쌓는다. 적립 이력은 ledger-db(원장 DB)에 기록한다.
point-wallet(포인트 지갑 API): 앱의 포인트 화면과 결제 때의 포인트 차감 요청을 처리한다. 자주 읽는 사용자별 포인트 요약은 redis-point(포인트 캐시)에 두고, 거래 내역은 ledger-db에서 읽는다.
coupon-svc(쿠폰 서비스): 쿠폰 발급과 회수를 맡는다. 발급 요청과 발급 결과는 kafka-main으로 주고받고, 발급 한도와 쿠폰 원장은 ledger-db에 둔다.
notify-hub(알림 허브): kafka-main에서 알림 이벤트를 읽어 푸시와 문자로 보낸다. 발송 결과도 kafka-main에 다시 낸다.
공통 구성요소
kafka-main: 서비스 사이의 이벤트를 나르는 메시지 브로커다. 토픽별 보존 기간은 config-center(설정 관리 서버)에 보관된 값을 따른다.
redis-point: point-wallet 전용 캐시다. 다른 서비스는 쓰지 않는다.
redis-session(세션 캐시): 로그인 세션 저장소다.
ledger-db: 결제, 정산, 포인트의 모든 거래 원장을 담는 주 데이터베이스다.
config-center: 서비스 설정 값을 버전별로 보관하고 운영 환경에 내려보낸다.
api-edge(외부 API 관문): 바깥에서 들어오는 모든 API 요청이 처음 거치는 곳이다.
