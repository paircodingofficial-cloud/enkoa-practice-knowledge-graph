플랫폼본부 조직과 운영 구성요소
기준일: 2026-09-30
플랫폼본부 세 팀이 운영하는 공통 구성요소와 온콜 담당자를 적는다. 여러 서비스가 함께 기대는 구성요소는 서비스 팀이 아니라 아래 팀이 운영한다. 이 표는 3분기 기준이다.
공통인프라팀: api-edge(외부 API 관문), config-center(설정 관리 서버), redis-session(세션 캐시), redis-point(포인트 캐시)를 운영한다. 온콜 담당자는 한도윤이다. 캐시 용량 증설 요청은 이 팀의 요청 게시판으로 받는다.
데이터플랫폼팀: ledger-db(원장 DB)를 운영한다. 온콜 담당자는 윤지아이다. 스키마 변경, 인덱스 추가, 연결 상한 조정은 이 팀의 검토를 거친다. 백업은 매일 새벽 두 차례 받는다.
메시징플랫폼팀: kafka-main(메인 메시지 브로커)과 notify-hub(알림 허브)를 운영한다. 온콜 담당자는 강태오이다. 새 토픽 생성과 보존 기간 변경은 이 팀이 검토한 뒤 config-center를 통해 반영한다.
온콜 연락 방법: 경보가 울리면 해당 팀 온콜 담당자에게 전화가 가고, 10분 안에 응답이 없으면 같은 팀 팀장에게 넘어간다. 팀장도 응답하지 않으면 본부 당직 책임자가 받는다.
