가맹점 연동 결제 거절 장애 보고서
발생일: 2026년 6월 3일
영향: 9시부터 10시 15분까지 가맹점 서버가 merchant-api(가맹점 API)로 보내는 주문 결제 요청이 모두 거절되었다. 온라인 가맹점 약 3,400곳에서 결제 실패가 났고, 앱 결제와 오프라인 결제는 영향이 없었다.
타임라인 요약: 09:00 merchant-api 요청 성공률이 0%로 떨어졌다. 09:08 가맹점들이 보안 연결 오류 화면을 보고 문의하기 시작했다. 09:20 api-edge(외부 API 관문)에 걸린 가맹점 전용 도메인 인증서가 이날 0시에 만료된 것을 확인했다. 09:50 새 인증서를 올렸고, 가맹점 쪽 연결이 새로 맺어지는 데 시간이 걸려 10:15에 모두 회복되었다.
직접 원인: 가맹점 전용 도메인의 서버 인증서가 만료되었다.
근본 원인: 인증서 갱신 안내 메일이 퇴사한 직원의 메일함으로 가고 있어 아무도 받지 못했다. 자동 갱신 대상에서도 빠져 있었다.
조치: 인증서를 교체하고 갱신 안내를 받는 곳을 개인 메일이 아닌 공용 메일 그룹으로 바꿨다.
재발 방지: 바깥에 노출된 모든 인증서의 만료일을 한 화면에서 보는 대시보드를 만든다. 만료 14일 전부터 매일 경보를 보낸다.
