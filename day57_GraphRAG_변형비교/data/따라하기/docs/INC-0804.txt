와일드카드 인증서 만료 결제 중단 장애 보고서
발생일: 2026년 8월 4일
영향: 9시 12분부터 9시 59분까지 47분 동안 앱과 웹의 모든 결제 요청이 실패했다. 결제 실패는 약 5만 6천 건으로 추산되며, 출근 시간대의 교통과 편의점 결제가 가장 크게 영향을 받았다.
타임라인 요약: 09:12 결제 성공률이 0%에 가깝게 떨어졌다. 09:15 앱에서 보안 연결 오류가 난다는 신고가 들어왔다. 09:24 api-edge(외부 API 관문)에 걸린 와일드카드 인증서가 09:12에 만료된 것을 확인했다. 09:45 비상 절차로 새 인증서를 발급해 올렸고 09:59 결제가 정상화되었다.
직접 원인: 앱과 웹이 접속하는 주 도메인의 와일드카드 인증서가 만료되어, 모든 클라이언트가 보안 연결을 맺지 못했다.
근본 원인: 이 인증서는 자동 갱신 도구에 등록되어 있었지만, 도메인 소유 확인용 레코드가 3월 DNS 이전 때 빠져 갱신이 두 달째 실패하고 있었다. 갱신 실패 경고는 로그에만 남고 경보로 이어지지 않았다.
조치: 인증서를 손으로 다시 발급하고, 소유 확인 레코드를 다시 등록했다.
재발 방지: 자동 갱신 실패를 경보로 올린다. 실제 서비스 중인 인증서의 남은 기간을 바깥에서 매일 확인하는 점검을 추가한다.
