# 과제 01 자료: 의약품 안내문

## 출처

- 식품의약품안전처 「의약품개요정보(e약은요)」, 공공데이터포털(data.go.kr) 제공
- 이용 조건: 공공누리 출처표시
- 수집일: 2026-07-10
- 단위프로젝트3 의약품 문서실 스냅샷(`drugs_snapshot.csv`)에서 골랐습니다. 본문은 원문 그대로이며, 항목 이름(제조사, 효능, 용법, 경고, 주의, 상호작용, 부작용)만 붙였습니다. 비어 있는 항목은 뺐습니다.
- 의학적 조언이 아니라 수업용 검색 자료입니다. 실제 복용은 의사·약사와 상의하세요.

## 파일

| 파일 | 내용 |
|---|---|
| `docs.jsonl` | 안내문 19편. 한 줄에 문서 하나이며 `doc_id`, `title`, `manufacturer`, `category`(감기약/소화제), `item_seq`(e약은요 품목기준코드), `text`(제목 줄을 뺀 본문)를 담습니다. |
| `docs/` | 같은 19편을 문서마다 텍스트 파일 하나로 나눈 것입니다(`<doc_id>.txt`, 첫 줄이 제품명). |
| `questions.json` | 방식 비교에 쓰는 골드 질문 8개입니다. |
| `extra.json` | 갱신 시연에 쓰는 추가 문서 1편의 `doc_id` 와 고른 이유입니다. 어떤 골드 질문의 근거도 아니며, 비교 세트에서는 빠집니다. |

## 문서 구성 (비교 세트 18편)

| 분류 | 편수 | 담긴 제품 |
|---|---|---|
| 감기약 | 9 | 지엘소브레롤캡슐(지엘파마), 리나치올캡슐500밀리그람(현대약품), 투렌정(태극제약), 한생액(현대약품), 코푸시럽에스(유한양행), 엑스펙토시럽2%(팜젠사이언스), 알파아세트아미노펜정500밀리그람(알파제약), 복합써스펜좌약(한미약품), 판콜에스내복액(동화약품) |
| 소화제 | 9 | 베아제정(대웅제약), 훼스탈플러스정(한독), 겔포스엠현탁액(보령), 가레오연질캡슐500밀리그램(조아제약), 파밀라제정(알파제약), 활명수(동화약품), 베스타제포르테정(동아제약), 갈타제산(현대약품), 파자임-95밀리그램이중정(부광약품) |

여러 문서가 같은 제조사나 같은 성분을 공유합니다(현대약품 3편, 동화약품 2편, 아세트아미노펜 3편, 카르보시스테인 2편 등). 멀티홉 질문은 이 제조사나 성분을 다리로 씁니다.

## 골드 질문 (`questions.json`)

필드: `id`, `qtype`(single, multihop, global), `question`, `gold_doc_ids`(정답 근거 문서: 답을 끌어내려면 읽어야 하는 문서).

| 유형 | 개수 | 설명 |
|---|---|---|
| 단일 사실 (single) | 3 | 한 안내문 안에 있는 상호작용·복용법을 묻습니다. 근거 문서는 1편입니다. |
| 멀티홉 (multihop) | 3 | 질문에 나온 제품에서 다리(제조사, 성분)를 찾고, 그 다리로 이어지는 다른 제품 안내문에서 답을 찾습니다. 다리와 답이 든 제품 이름은 질문에 없습니다. 근거 문서는 2편이며 `gold_doc_ids` 는 따라가는 순서입니다. |
| 전역 (global) | 2 | 여러 안내문에 흩어진 주의 문구를 모아 답합니다. 근거 문서는 5편, 8편입니다. |

- 근거 문서 포함률(검색이 넘긴 문서에 `gold_doc_ids` 가 몇 편 들었는지)로 방식을 비교합니다.
- 자료와 골드 질문은 강사용 생성 스크립트로 만들고 스스로 검사했습니다.
