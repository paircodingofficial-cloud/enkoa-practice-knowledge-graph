# 과제 02 자료: 의약품 안내문

## 출처

- 식품의약품안전처 「의약품개요정보(e약은요)」, 공공데이터포털(data.go.kr) 제공
- 이용 조건: 공공누리 출처표시
- 수집일: 2026-07-10
- 단위프로젝트3 의약품 문서실 스냅샷(`drugs_snapshot.csv`)에서 골랐습니다. 본문은 원문 그대로이며, 항목 이름(제조사, 효능, 용법, 경고, 주의, 상호작용, 부작용)만 붙였습니다. 비어 있는 항목은 뺐습니다. 원문에 끊긴 문장이 있으면 그대로 두었습니다.
- 의학적 조언이 아니라 수업용 검색 자료입니다. 실제 복용은 의사·약사와 상의하세요.

## 파일

| 파일 | 내용 |
|---|---|
| `docs.jsonl` | 안내문 19편. 한 줄에 문서 하나이며 `doc_id`, `title`, `manufacturer`, `category`(알레르기약/피부약), `item_seq`(e약은요 품목기준코드), `text`(제목 줄을 뺀 본문)를 담습니다. |
| `docs/` | 같은 19편을 문서마다 텍스트 파일 하나로 나눈 것입니다(`<doc_id>.txt`, 첫 줄이 제품명). |
| `questions.json` | 방식 비교에 쓰는 골드 질문 8개입니다. |
| `extra.json` | 문서 추가·삭제 시연용 지정입니다. `insert` 는 나중에 넣을 문서 1편(비교 세트에서 빠짐), `delete` 는 비교 세트 안에서 지울 문서 1편과 답이 바뀌는 질문 ID 입니다. |

## 문서 구성 (비교 세트 18편)

| 분류 | 편수 | 담긴 제품 |
|---|---|---|
| 알레르기약 | 7 | 노타민정(안국약품), 알레그라정120밀리그람(한독), 페니라민정(유한양행), 마스질정(태극제약), 알레리진정(이연제약), 알레크롬점안액(이연제약), 나리스타에스점비액(삼천당제약) |
| 피부약 | 11 | 리카에이크림(보령), 버물리에스액(현대약품), 물린디액(신신제약), 보송크림(안국약품), 태극케토코나졸크림(태극제약), 베로아크림(태극제약), 제이알히드로코르티손연고(비보존제약), 후시딘연고(동화약품), 신신티눈고(신신제약), 라미실덤겔1%(지피테라퓨틱스코리아), 로푸록스네일라카(한독) |

여러 문서가 같은 제조사를 공유합니다(태극제약 3편, 안국약품 2편, 이연제약 2편 등). 멀티홉 질문은 이 제조사나, 안내문이 함께 쓴다고 적은 약의 성분을 다리로 씁니다.

## 골드 질문 (`questions.json`)

필드: `id`, `qtype`(single, multihop, global), `question`, `gold_doc_ids`(정답 근거 문서: 답을 끌어내려면 읽어야 하는 문서).

| 유형 | 개수 | 설명 |
|---|---|---|
| 단일 사실 (single) | 3 | 한 안내문 안에 있는 복용·사용법을 묻습니다. 근거 문서는 1편입니다. |
| 멀티홉 (multihop) | 3 | 질문에 나온 제품에서 다리(제조사, 함께 쓰는 약의 성분)를 찾고, 그 다리로 이어지는 다른 제품 안내문에서 답을 찾습니다. 다리와 답이 든 제품 이름은 질문에 없습니다. 근거 문서는 2편 또는 3편이며 `gold_doc_ids` 는 따라가는 순서입니다. |
| 전역 (global) | 2 | 여러 안내문에 흩어진 내용을 모아 답합니다. 근거 문서는 6편씩입니다. |
