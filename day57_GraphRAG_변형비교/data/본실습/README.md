# 본 실습 자료: 섬진강 곡성·구례 관광지 안내

## 출처

- 한국관광공사 TourAPI 「국문 관광정보 서비스」(KorService2), 공공데이터포털(data.go.kr) 제공
- 대상 지역: 전남 곡성군, 구례군
- 수집일: 2026-10-08
- 이용 조건: 공공누리 제1유형(출처표시) 문서만 사용했습니다. 제3유형(변경 금지)과 유형 표시가 없는 문서는 넣지 않았습니다.
- 본문은 HTML 태그와 공백만 정리했고 내용은 고치지 않았습니다. 오탈자도 원문 그대로입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `docs.jsonl` | 관광지·문화시설·레포츠 개요 33편. 한 줄에 문서 하나이며 `doc_id`, `title`, `county`(곡성군/구례군), `content_type`, `address`, `text` 를 담습니다. |
| `docs/` | 같은 33편을 문서마다 텍스트 파일 하나로 나눈 것입니다(`<doc_id>.txt`). |
| `questions.json` | 방식 비교에 쓰는 골드 질문 12개입니다. |
| `aliases.json` | 같은 대상을 다르게 부르는 표기 묶음입니다(노트북은 읽지 않으며, 부록의 측정에 썼습니다). `on_gold_path` 는 골드 질문의 근거 경로와 겹치는지 표시합니다. |
| `hippo_triples.json` | 문서별 트리플(주어-서술어-목적어)입니다. 노트북은 읽지 않으며, 부록의 측정에 썼습니다. 같은 대상의 표기를 하나로 맞춰 미리 만들어 두었습니다. |
| `extra.json` | 교안 01의 GraphRAG 갱신과 교안 02의 LightRAG 문서 추가·삭제에서 넣는 추가 문서 1편의 `doc_id` 와 고른 이유입니다. 이 문서는 어떤 골드 질문의 근거도 아니며, 방식 비교 세트에서는 빠집니다. |
| `prebuilt/` | 교안 01·02 색인을 강사가 같은 설정으로 미리 만든 것입니다. 내용과 만든 조건은 [prebuilt/README.md](prebuilt/README.md)에 있습니다. |

## 골드 질문 (`questions.json`)

필드: `id`, `qtype`(single, multihop, global), `question`, `gold_doc_ids`(정답 근거 문서: 답을 끌어내려면 읽어야 하는 문서).

| 유형 | 개수 | 설명 |
|---|---|---|
| 단일 사실 (single) | 4 | 한 문서 안에 있는 연도·규모·수치·인물을 묻습니다. 근거 문서는 1편입니다. |
| 멀티홉 (multihop) | 5 | 첫 문서에서 찾은 개체(함께 나온 장소, 인물, 물길 등)를 다른 문서에서 다시 찾아야 답이 나옵니다. 질문은 출발점(첫 문서의 대상)을 이름으로 말하고, 두 문서를 잇는 개체와 답이 든 문서의 제목은 말하지 않습니다. 근거 문서는 2편 또는 3편이며 `gold_doc_ids` 는 따라가는 순서입니다. |
| 전역 (global) | 3 | 여러 문서에 흩어진 공통 주제를 모아 답합니다. 한 문서가 주제를 정리해 주지 않습니다. 근거 문서는 4~6편입니다. |

- 교안은 검색이 답변 모델에 넘긴 문서에 `gold_doc_ids` 가 몇 편 들었는지(근거 문서 포함률)만 셉니다. 답변은 채점하지 않습니다.
- 자료와 골드 질문은 강사용 생성 스크립트로 만들고 스스로 검사했습니다.
